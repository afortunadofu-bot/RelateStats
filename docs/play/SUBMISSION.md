### 2.8 無障礙 API 聲明 ⚠️ 最重要

Play Console → 應用程式內容 → **權限聲明 / 無障礙 API**。

**Q：應用程式是否使用 AccessibilityService API？**
是

**Q：應用程式是否為無障礙輔助工具（`isAccessibilityTool`）？**
否（`accessibility_service_config.xml` 已設 `android:isAccessibilityTool="false"`）

**Q：請說明應用程式的核心功能**

```
RelateStats 是個人社交時間統計工具，在使用者自己的手機上統計他與聯絡人在通訊 App 上的互動，
包括訊息數、聊天時段，以及在每個聊天室停留的時間，並以圖表呈現。
所有資料只存在裝置上，App 沒有網路權限。
```

**Q：請說明如何使用 AccessibilityService API，以及為什麼必須使用**

```
「聊天室停留時間」是本 App 的核心統計之一。要知道使用者正在看哪個聊天室，
必須在使用者開啟通訊 App 時，擷取畫面頂端的聊天室名稱。

使用方式：
・只處理 LINE、Messenger、Instagram、WhatsApp、Telegram、Threads 與電話 App 的事件，其他 App 的事件一律忽略。
・監聽 TYPE_WINDOW_STATE_CHANGED 與 TYPE_WINDOW_CONTENT_CHANGED，比對標題列的 view id，取出聊天室名稱。
・記錄「聊天室名稱、App 名稱、開始與結束時間」，計算停留秒數。
・不保存訊息內容，不執行任何動作（不點擊、不輸入、不捲動、不變更設定）。

為什麼無法用其他 API：
・UsageStatsManager 只能提供 App 層級的使用時間，無法知道使用者在 App 裡的哪個聊天室。
・通知存取只在收到訊息時觸發，無法得知使用者主動開啟並停留在聊天室的時間。
・Android 沒有其他公開 API 能取得第三方 App 目前顯示的畫面標題。
```

**Q：透過 API 收集哪些使用者資料？是否分享？**

```
只擷取聊天室名稱與時間。資料只儲存在使用者裝置上，
App 沒有 INTERNET 權限，不會傳送或分享給開發者或任何第三方。
```

**Q：明確揭露與同意**

```
使用者在 App 內點「無障礙服務」時，會先顯示專門的說明畫面（標題「開啟『無障礙服務』前請先了解」），
說明會讀取的內容、用途、不會做的事、資料只存在手機，
使用者必須按「同意並前往設定」才會開啟系統無障礙設定頁；按「不同意」則不會開啟，App 其餘功能照常使用。
系統無障礙設定頁的服務說明也有相同內容。
```

## 3. 無障礙聲明影片腳本

- 長度：60～90 秒，直式，手機螢幕錄影（系統內建螢幕錄影即可）
- 用**測試帳號與範例對話**，不要出現真實聯絡人；錄影前先打開「設定 → 偏好 → 截圖模式」
- 不需要配音，可以在剪輯時加字幕說明每一步
- 上傳 YouTube → 設為「不公開」

| 秒數 | 畫面 | 字幕 |
|------|------|------|
| 0–5 | 開啟 RelateStats 主畫面 | RelateStats：個人社交時間統計，資料只存在手機 |
| 5–15 | 設定 → 服務 → 點「無障礙服務」 | 開啟無障礙服務前，App 先顯示說明 |
| 15–30 | 停在揭露畫面，慢慢捲動 | 說明讀取內容：只擷取聊天室名稱，不保存訊息內容 |
| 30–35 | 按「不同意」，回到設定頁 | 不同意就不會開啟，App 照常使用 |
| 35–40 | 再點一次，按「同意並前往設定」 | 同意後才前往系統設定 |
| 40–50 | 系統無障礙設定 → RelateStats → 開啟（畫面上看得到服務說明） | 系統設定頁同樣標示用途 |
| 50–65 | 開 LINE（測試帳號），進一個聊天室停留約 10 秒，離開 | 在聊天室停留時，只記錄聊天室名稱與時間 |
| 65–80 | 回 RelateStats → 排行／聯絡人，看到該聊天室的停留時間 | 用途：計算在每個聊天室停留多久 |
| 80–90 | 設定頁「隱私權政策」 | App 沒有網路權限，資料不會上傳 |

## 5. 封閉測試招募

### 招募訊息

```
我做了一個 Android App「RelateStats」，會統計你在 LINE、IG 等通訊 App 上跟誰聊最多、在哪個聊天室停留最久。
上架 Google Play 前需要 12 位以上的朋友幫忙測試 14 天。

需要你做的事：
1. 用 Android 手機，把你的 Gmail 給我，我加進測試名單
2. 點我傳給你的連結，按「成為測試人員」，再從 Play 商店安裝
3. 接下來 14 天不要解除安裝，每天打開看一下就好
4. 有任何問題或建議直接跟我說

隱私：App 沒有網路權限，你的資料只存在你自己的手機，我完全看不到。
```

### 回饋問卷（Google 表單）

1. 手機型號與 Android 版本
2. 你主要用哪些通訊 App？
3. 開權限的說明看得懂嗎？有沒有讓你不敢開？
4. 有沒有哪個數字看起來不對？（例如停留時間是 0、訊息數明顯少）
5. 最有用／最沒用的功能是什麼？
6. 有沒有閃退或卡住？在哪個畫面？
7. 其他建議

### 申請正式版存取權時的回答素材

- **招募方式**：朋友與同事，透過 Google 群組管理名單
- **測試期間的使用情況**：測試人員每天使用，涵蓋 LINE、IG、Messenger 等不同通訊 App 與多種機型
- **根據回饋的修改**：整理 `docs/CHANGELOG.md` 中封閉測試期間的版本
- **為什麼準備好上架**：核心統計在多種機型上驗證正確、權限揭露經測試人員確認易懂、無未解決的閃退
