# RelateStats 品牌規範

這份文件是「識別長什麼樣、為什麼這樣、哪裡不能改」的單一來源。
改動任何一項之前先讀完對應段落——多數規則背後都有踩過的坑。

---

## 1. 名稱

| 用途 | 寫法 |
|------|------|
| 正式名稱 | `RelateStats`（一個字，字中的 S 大寫，中間不空格、不加連字號） |
| 商店標題 | `RelateStats：社交時間統計`（全形冒號） |
| 套件名稱 | `com.relatestats.app`（**上架後永遠不能改**） |
| Kotlin 套件路徑 | `com.example.relatestats`（Play 不看這個，維持原狀即可） |
| 系統服務名稱 | `RelateStats 通知監聽`、`RelateStats 停留時間監測` |

⚠️ 不要寫成 `Relatestats`、`RELATESTATS`、`Relate Stats`。
使用者在系統設定頁找服務時是用眼睛掃字串的，大小寫不一致會讓人以為是兩個 App。

---

## 2. 標語

```
看見你把時間花在誰身上
```

出現在：

- 商店「簡短說明」的第一句
- App 內首次啟動引導頁的第一頁標題
- 設定頁捲到底的品牌區
- 「分享給朋友」的分享文字
- 社群宣傳圖

⚠️ 程式裡一律引用 `BRAND_TAGLINE` 常數，不要各寫一份。
品牌就是同一句話到處都一樣——改一邊沒改另一邊，比沒寫還糟。

## 3. 記號（mark）

三個大小遞增、彼此交疊的圓 ＝ 人，以及你跟他們重疊多少。
圓越大表示佔掉你越多注意力；最大的那顆用品牌藍點出重點。

**同一組比例存在四個地方，改一個就要四個一起改：**

| 檔案 | 用途 |
|------|------|
| `res/drawable/ic_launcher_foreground.xml` | 桌面圖示、啟動畫面 |
| `res/drawable/ic_stat_relate.xml` | 狀態列通知圖示（24dp 版） |
| `MainActivity.kt` 的 `BrandMark()` | App 內（標題列、引導頁、設定頁頁尾） |
| `上架素材/03_圖示_512x512/icon_512.png` | 商店圖示 |

比例（108 畫布）：圓心 x = 30 / 48 / 70，半徑 = 9 / 13 / 18，垂直置中。
透明度：0.55 / 0.85 / 1.0（最大的那顆是實心品牌藍）。

### 畫法上的硬規則

- **只用實心形狀**。不用細線、不用細環：縮到 16px 時 1px 以下的線會整條消失，
  「關係」只能靠圓的**交疊**表達。
- **全部落在 108 畫布的中央 72×72 安全區（18..90）內**，
  否則不同廠商的圓形／方形遮罩會把邊緣切掉。
- **底色不做漸層或紋理**。縮到 24px 時任何裝飾都會糊成雜訊，單色反而最好認。
- **狀態列圖示只有 alpha 有意義**。系統會把整張圖塗成白色，顏色寫什麼都沒用。

## 4. 顏色

定義在 `res/values/colors.xml`：

| 名稱 | 值 | 用途 |
|------|-----|------|
| `brand_ink` | `#0F172A` | 記號底色、啟動畫面底色 |
| `brand_blue` | `#3B82F6` | 記號裡最大的那顆圓 |
| `brand_light` | `#F8FAFC` | 記號裡其餘的圓（搭配 alpha 分層） |

### ⚠️ 品牌色與「配色」是兩回事

App 內的**配色**（設定 → 偏好 → 配色，`AppColors.Chart`）換的是**資料的顏色**，
使用者想換幾次都可以。**記號的顏色在任何配色、任何深淺模式下都不變**——
記號跟著配色變，等於每個人看到的是不同的 App。

深色模式下唯一的例外：墨藍底壓在深色卡片上幾乎沒有輪廓，
所以 `BrandMark()` 會補一圈 `BorderStrong` 細框。**只補輪廓，顏色不動。**

## 5. 啟動畫面

| 系統版本 | 由誰負責 |
|----------|----------|
| Android 11 以下 | `res/drawable/launch_background.xml`（墨藍底 + 記號）掛在 `Theme.RelateStats.Launch` 的 `windowBackground` |
| Android 12 以上 | `res/values-v31/themes.xml` 的 `windowSplashScreenBackground` + `windowSplashScreenAnimatedIcon` |

⚠️ `MainActivity.onCreate` **必須**在 `super.onCreate()` 之前 `setTheme(R.style.Theme_RelateStats)`
把主題換回來，否則整個 App 的視窗底色都會是墨藍。

⚠️ `windowSplashScreenAnimatedIcon` 只放前景（記號本身）。
放整顆 `ic_launcher` 的話系統會再套一次圓形遮罩，看起來像圖示破了一個洞。

## 6. 作者歸屬

App 內顯示在**設定頁最下方**（`SettingsScreen` 的頁尾）：

```
RelateStats v<版本>

開發與著作權　RelateStats
聯絡信箱　　　celine.fu.work@gmail.com
© <年> RelateStats
```

⚠️ **版本號旁邊一定要寫品牌名稱**（`RelateStats v1.0.0`，不是只寫 `v1.0.0`）。
使用者回報問題時截的就是這一行，沒有名稱就看不出是哪個 App。

⚠️ 作者歸屬掛**品牌名稱**，不是個人姓名。
⚠️ 信箱在程式裡是 `FEEDBACK_EMAIL` 常數，同時用於意見回饋。
要改信箱的話，`docs/play/SUBMISSION.md`（開發人員聯絡資訊）與
`docs/privacy-policy.html` 也要一起改，三處必須一致。

⚠️ **「品牌化」的範圍就是這一塊。** 識別記號、配色、啟動畫面、通知圖示、
首次啟動引導頁都不在範圍內，要動那些一律先問過再動。

## 7. 語氣

寫給使用者看的字（引導頁、說明、通知、商店文案）遵守：

- **講具體的東西，不講形容詞**。
  ✅「跟誰聊最多、在哪個聊天室停留最久」 ❌「洞察社交能量」
- **數字與名詞要對得上實際畫面**。
  分頁有五個就寫五個；第一個分頁叫「概況」就不要寫「總覽」。
  首次啟動就講錯名稱，使用者會照著找卻找不到。
- **隱私一律講清楚、講在前面**：「資料只存在這支手機」「App 沒有網路權限」。
  這是這個 App 最大的差異點，不是免責聲明。
- **不承諾做不到的事**。少數機型抓不到通話秒數就直說。
